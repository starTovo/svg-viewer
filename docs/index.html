SVG 查看器

安卓手机 / 平板上的 SVG 查看与编辑工具 —— 打开、改代码、看效果、导出 PNG，全程离线可用。

单一 HTML 文件 离线可用 Android 8.0+ AI 辅助开发

  • 打开本地 SVG，或从文件管理器直接「用其他应用打开」
  • 编辑源码：一键清空、多步撤销重做、语法排错会直接报出行号列号并跳到出错位置
  • 查看：双指缩放（0.1x–8x）、单指平移、双击放大、棋盘格看透明背景
  • 导出 PNG（2x 清晰度）或保存 SVG，可自定义导出目录
  • 写代码写坏了也不怕：画面保留上一次成功渲染，只在下方提示哪里出错
